### Lessons

- **The publication guard checks commit *messages*, not just staged files**
  (`--messages <range>`). Mentioning a client token anywhere in the message
  fails CI; the neutral `TKT-<num>` form is mandatory.
- **`git rebase -i --root` replays the *entire* repo history, not just the PR's
  tip commits.** Use a targeted `rebase <parent-of-first-pr-commit>` to reword a
  single commit.
- **ansible-lint treats role-name + `yaml[new-line-at-end-of-file]` as hard
  errors** in the CI `lint` job; `make lint` reproduces them locally.
- GitHub can take a couple of minutes to fire CI after a force-push; if no run
  appears, re-query before concluding anything.
