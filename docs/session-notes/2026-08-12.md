## Review fixes worth remembering

- **#200 review** (pinned to SHA) caught two real bugs, both fixed before merge:
  `init` clobbered a pre-existing `.opskit/README.md` without `--force`; `check`
  crashed with a `TypeError` on a malformed manifest instead of reporting it.
- **sync-agents lesson (#63):** OpenCode silently ignores a *nested*
  `permission.tool:` block in an agent file — tool globs must sit directly under
  `permission:`. `opencode agent list` *displayed* the nested rule, which fooled
  an earlier "sandbox verified" claim. Verify enforcement behaviorally, not by
  the list command. Fixed to flat form + guarding tests.
