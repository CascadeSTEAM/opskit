# bwunlock

Call the skill tool to load the `bwunlock` skill, then follow its instructions
exactly — run `bin/bwunlock.sh --check`, then `bin/bwunlock.sh` to pop the
password dialog, verify with a second `--check`, and report the source and state
without ever printing a token or password.
