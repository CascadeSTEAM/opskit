# /triage — repo-wide critical review → measurable, prioritized GitHub issues

## Description

Repo-wide critical review: triage GitHub backlog, review code at a SHA, file measurable findings, apply one priority rubric

## Triggers

`/triage`, `triage repo`, `repo triage`, `triage issues`, `triage code`, `triage the backlog`, `critical review`, `reconcile issues`, `prioritize issues`, `priority sweep`

## Modes

`/triage full` — full pass (default)
`/triage code [paths]` — review specific paths only
`/triage issues` — survey open issues only
`/triage ideas` — triage docs/ideas.md ledger only
`/triage board` — board plan dry-run or apply
`/triage status` — re-print latest report
`/triage apply` — re-present report and ask again, then apply

## Procedure

Load the `triage` skill and run mode X.
